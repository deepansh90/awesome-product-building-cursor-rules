Use `ui-ux-pro-max-skill` design system patterns for fast UI system recommendations.

When invoked:

1. Identify product type, target platform (web/mobile/game), and stack.
2. Propose one recommended design direction (style, color, typography) with a short rationale.
3. Apply relevant local rules:
   - `website-building.mdc` for websites/SPAs
   - `mobile-app-building.mdc` for mobile apps
   - `games-building.mdc` for games
4. Keep output concise and actionable.
