# UI UX Pro Max Fast Recommendation

Use this skill when the user asks for quick UI system recommendations.

## Core instruction

For fast UI system recommendations, use `ui-ux-pro-max-skill` design system patterns.

## Workflow

1. Identify:
   - product type
   - target surface (`website`, `mobile app`, `game`)
   - stack/framework
2. Recommend:
   - one style direction
   - one palette direction
   - one typography direction
3. Validate against local rule files:
   - `create-web-game.mdc`
   - `convert-web-to-mobile.mdc`
   - `create-web-game.mdc`
4. Return concise implementation-ready guidance.
